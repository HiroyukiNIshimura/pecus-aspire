# Coati コードベース解説

この資料は、Coati（開発コード `pecus-aspire`）の**現在の実装をコードから読み解くための技術解説**です。仕様の唯一の正や、操作手順書ではありません。

## 読み方と根拠

- 現行動作の説明は、リンク先のソースコード・プロジェクト定義を根拠にしています。ページ内のコードリンクはリポジトリルートからの相対リンクです。
- 設計意図や過去の計画は、必要に応じて既存の`docs/spec/`および`docs/`のガイドラインに案内します。計画文書の内容が現行実装と一致するとは限りません。
- 根拠を確認できない事項は断定しません。設定値・認証情報・生成済みの設定ファイルは掲載しません。
- 内容はコード変更に伴って古くなります。最終確認日と根拠コードを参照してください。
