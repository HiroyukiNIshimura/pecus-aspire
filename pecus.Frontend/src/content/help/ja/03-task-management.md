# タスク管理機能

ワークスペース内のタスクを効率的に管理するための機能について説明します。

## タスク一覧の見方と基本操作

アイテム詳細の「タスク」欄で、そのアイテムのタスクを確認します。

![タスク一覧と絞り込み](/help/images/1000039.webp)

一覧では、ステータス、並び順、担当者でタスクを絞り込めます。並び順は「シーケンス」「優先度」「期限日」から選び、昇順・降順を切り替えます。担当者欄の「自分」を選ぶと、自分が担当するタスクに絞り込めます。件数が多い場合は、一覧左右のページ送りを使います。

タスクカードにはタスク番号、内容、優先度、進捗、担当者、期限日が表示されます。コメントに「助けて」または「督促」が含まれる場合は、カードにもバッジが表示されます。編集権限がある場合は、カードの編集ボタンから詳細を開けます。

## タスクのステータス
タスクは以下のステータスを持ちます。一覧画面でフィルタリングして表示できます。

- **未完了 (Active)**: 現在進行中または着手待ちのタスクです。
- **完了 (Completed)**: 作業が終了したタスクです。
- **破棄 (Discarded)**: 不要になった、または中止されたタスクです。

一覧では「未完了」「完了」「破棄」を選択でき、「すべて」で絞り込みを解除できます。

## タスクの作成と編集

アイテム詳細の「タスク追加」から作成します。タスクタイプ、担当者、タスク内容、期限日を入力します。優先度を選び、必要に応じて開始日、予定工数、先行タスクを設定して作成します。組織設定によっては、予定工数の入力が必須です。

![タスク作成フォーム](/help/images/1000041.webp)

先行タスクは複数選択できます。選択したタスクが完了するまで後続タスクには着手できません。先行タスクの期限日が新しいタスクの期限日より後の場合は、日付の矛盾が警告されます。

AIを利用できる組織では、タスクタイプを選んで「提案を利用」を押すと、タスク内容の案を取得できます。提案内容は必要に応じて編集してから保存してください。

タスクカードの編集ボタンを押すと詳細画面が開きます。内容、担当者、優先度、開始日・期限日、先行タスクのほか、予定・実績工数や進捗率を更新して「保存」します。完了または破棄の状態も変更でき、破棄にする場合は理由を入力します。閲覧専用の権限では編集できません。

## タスク詳細とコメント
タスク詳細画面では、進捗状況の更新やメンバー間のコミュニケーションが行えます。

![タスク詳細とコメント](/help/images/1000040.webp)

### コメント機能
目的に応じてコメントの種類を使い分けることで、円滑なコミュニケーションを支援します。

- **通常**: 一般的な連絡や報告に使用します。
- **メモ**: 個人の備忘録として使用します。
- **助けて**: 作業に行き詰まった際、他のメンバーに支援を求めるために使用します。
- **返事が欲しい**: 特定のメンバーからの回答が必要な場合に使用します。
- **リマインダー**: 特定の日時に通知を受け取りたい場合に使用します。
- **督促**: 期限が迫っているタスクに対して注意を促す場合に使用します。

利用できるコメントの種類はユーザーの役割によって異なります。タスク担当者は「通常」「メモ」「助けて」「返事が欲しい」「リマインダー」を選べます。アイテムのオーナー・担当者・コミッター（タスク担当者を除く）は「通常」「返事が欲しい」「督促」を選べます。それ以外のメンバーが選べるのは「通常」です。

## タスクフローマップ
タスク間の依存関係（先行・後続）を視覚的に確認できる機能です。
アイテム詳細画面の「フローマップ」ボタンから表示できます。

### チェーンモード
ここをやっつけないとまずいぞ！というタスクのチェーンを上から順番に表示します。

![画面](/help/images/1000008.webp)

### グラフモード
タスク全体の関連を見える化するグラフモードも利用可能です。

![画面](/help/images/1000026.webp)


### 主な機能
**クリティカルパス**:
最も時間がかかる作業経路です。このパス上のタスクが遅れると、全体の完了が遅れます。
- 赤枠で強調表示されます。
- 「212日」のように残り合計期間が表示されます。
- 矢印（→）で先行タスクから後続タスクへの流れを示します。

**依存チェーン**:
クリティカルパス以外の依存関係のあるタスク群です。

- 期間の長い順に並んでいます。
- 各チェーンには「○ステップ」「○日」の情報が表示されます。

**独立タスク（依存関係なし）**:
他のタスクに依存せず、いつでも着手できるタスクです。

- 並行して作業を進められます。
- 先行タスクを設定すると、依存チェーンに組み込まれます。

### タスクカードの見方
| 表示 | 意味 |
|---|---|
| 🟢 緑のプログレスバー | 進捗率（0〜100%） |
| 🔴 緊急 バッジ | 優先度が「緊急」のタスク |
| ⚠️ 黄色の日付 | 先行タスクの期限が後続より遅い（スケジュール矛盾） |
| 👤 アイコン | 担当者 |
| 📅 日付 | 期限日 |

### 上部の統計情報
| 項目 | 説明 |
|---|---|
| 総タスク | アイテム内のタスク総数 |
| 着手可能 | 今すぐ作業を始められるタスク数 |
| 待機中 | 先行タスクの完了を待っているタスク数 |
| 完了 | 完了済みのタスク数 |
| 合計期間 | 未完了タスクの推定所要日数（土日除く） |
| 担当者 | 関わっている担当者の人数 |

💡 ヒント
- 編集権限があれば、タスクカードの編集ボタンからタスクの詳細を開けます。
- 「先行タスク」を設定すると、タスク間の依存関係を作れます。
- クリティカルパス上のタスクを優先的に進めると、全体の遅延を防げます。
- フローマップは1つのアイテムのタスクを表示します。別のアイテムのタスクを見る場合は、対象アイテムを選んでからフローマップを開きます。

### 活用方法
- **着手可能タスクの特定**: 先行タスクが完了し、すぐに着手できるタスクを一目で把握できます。
- **ボトルネックの発見**: 多くのタスクが依存しているタスク（ボトルネック）を特定し、優先的に対応する計画を立てられます。

## 担当者の負荷確認
タスク作成・編集時に担当者と期限日を指定すると、担当者の期限切れ・今週が期限のタスク・未完了タスク・担当ワークスペース数などの負荷状況が表示されます。同じ期限日の担当タスクが設定された閾値を超えている場合は警告されます。無理のないスケジュール調整に役立ちます。

## タスク期間の計算方法
タスクの所要期間は、以下のルールで自動計算されます。

### 基本ルール
**推定工数が設定されている場合**

入力した推定工数を「1日 = 8時間」として日数に換算します。
例：16時間 → 2日、4時間 → 0.5日

**推定工数が未設定の場合**

開始日から期限日までの営業日（土日を除く）で計算します。
祝日は営業日としてカウントされます。

### 開始日の決め方
開始日は以下の優先順位で自動決定されます：

- 開始日が設定されている場合 → その日付を使用
- 先行タスクがある場合 → 先行タスクの期限日を使用
- どちらもない場合 → タスク作成日を使用

💡 ポイント
- 完了済み・破棄済みのタスクは期間計算から除外されます。
- より正確な期間を表示するには、見積もり工数を入力することをおすすめします。
- 先行タスクの期限日が後続タスクの期限日より後の場合、スケジュールの矛盾として警告が表示されます。
- タスクはアイテム内に50件までの制限を持っています。

## AIによるタスク自動生成機能

組織設定でAIを利用する設定がされている場合のみ、ワークスペース、アイテムの情報からAIが自動でタスクを生成する機能が利用できます。
ただし、AIにはメンバーの資質やアイテムの完全な内容などまでは推測できませんのであくまでテンプレート程度として利用してください。

タスク自動生成に最低限必要なのは開始日だけです。
![画面](/help/images/1000027.webp)
少し時間を要しますが、自動生成が完了すると提案画面を表示します。
![画面](/help/images/1000028.webp)
提案内容はチェックBOXで採用しないとすることもできますし、アコーディオンを開いて、作成するタスク内容の修正も可能です。
![画面](/help/images/1000029.webp)
提案内容を修正後にタスクを作成ボタンを押すことで、初めて実際のタスクが作成されます。再作成では、追加内容や修正依頼を追記して再作成を依頼可能です。

💡 ポイント
- より適切なタスク提案を得るには、アイテムのドキュメント内容を充実させてください。
- AIによるタスク担当者振り分けは、ワークスペース内のメンバーのスキルやタスク負荷状況を考慮します。適切なメンバーが選ばれるよう、メンバーのスキル情報をきちんと設定しておくことをお勧めします。
- 生成されたタスクはあくまで提案ですので、内容をよく確認し、必要に応じて修正してください。
